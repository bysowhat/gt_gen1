# 04 — 数据格式

本文档汇总流水线各环节的数据结构、字段含义与张量形状。
约定：`M` = 候选机器人位姿数 / 观测点数，`N` = 焊缝采样点数，`B` = batch 数，`D = 6` = 关节自由度，`7` = 位姿 `(x,y,z, qw,qx,qy,qz)`。

---

## 1. 输入：每条焊缝的 seam `.pkl`

`INPUT_ROOT/<folder>/<seam>.pkl`，`pickle.load` 后是一个 dict（`optimize_pose.py` `process()` 读取）：

| 键 | 形状 | dtype | 含义 |
|----|------|-------|------|
| `robot_pose` | `(M, 7)` | float | M 个候选机器人底座位姿（世界系） |
| `piece_pose` | `(M, 7)` | float | 对应的工件位姿（世界系） |
| `seam_line` | `(N, 3)` | float | 焊缝中心线采样点（工件系） |
| `seam_tangent` | `(N, 3)` | float | 每点焊缝切向（单位向量） |
| `seam_limits` | `(N, 2, 3)` | float | 每点两条坡口侧面方向向量 |
| `horizontal` | `(M,)` | int | 每个候选位姿下工件取向：0=水平，1=垂直（决定关节限位） |

工件几何由同目录的 `.usd` 提供（碰撞/遮挡），可选 `.ply` 点云。

---

## 2. Pose 输出：`output/<folder>/pose/<seam>.pkl`

`pickle.load` 后是一个 **list**，每个候选机器人位姿（求解成功的）对应一个 `output_single` dict
（`optimize_pose.py` 第 174–186 行）：

| 键 | 形状 | 含义 |
|----|------|------|
| `robot_pose` | `(7,)` | 机器人位姿（**工件系相对位姿**，`scene.reset` 返回的 `robot_pose_rel`） |
| `cam_pose` | `(A', B, 7)` | 相机观测位姿。`B` = 该方案的观测点个数；`A' = num_snapshots × A` = 精修产生的多套候选 |
| `joint` | `(A', B, 6)` | 与 `cam_pose` 对应的关节角（Traj 阶段读取此字段作为观测点目标） |
| `start_pts` | `(A', B)` | 每个观测点覆盖焊缝段的起始索引（已映射回原始焊缝方向） |
| `end_pts` | `(A', B)` | 每个观测点覆盖焊缝段的终止索引 |
| `horizontal` | int | 工件取向标志 |
| `seam_median` | `(3,)` | 焊缝中点（Traj 视野代价目标） |
| `piece_pose_original` | `(7,)` | 原始世界系工件位姿 |
| `robot_pose_original` | `(7,)` | 原始世界系机器人位姿 |
| `seam_line` | `(N, 3)` | 原始焊缝中心线 |
| `seam_limits` | `(N, 2, 3)` | 原始坡口方向 |

> `B` 是「观测点数」（走完整条焊缝所需的最少拍摄次数）；`A'` 是「同一观测方案的姿态多样本数」
> （精修阶段每 `span` 轮存一张快照 × 多个等优方案）。
> Traj 阶段的 `fixed_pts = data["joint"]` 形状即 `(N=A', M=B, 6)`。

### `path.json`：`output/<folder>/path.json`
```json
{ "usd_path": "/abs/path/to/piece.usd", "pc_path": "/abs/path/to/cloud.ply" }
```
由 Pose 阶段写出，Traj 阶段读取以定位工件 USD（建场景用）。

---

## 3. Traj 输出：`output/<folder>/traj/<seam>.pkl`

`pickle.load` 后是一个 **list**，每个 `output_single`（`optimize_traj.py` 第 203–211 行）：

| 键 | 形状 | 含义 |
|----|------|------|
| `robot_pose` | `(7,)` | 机器人底座位姿（工件系，已叠加 `[0,0,0.26]`+绕z90° 的 base 变换） |
| `trajectory` | `(num_batch=24, 6, T_total)` | 24 条关节空间轨迹，`T_total` 为各段拼接后的总时间步 |
| `idx_3d` | `(T_total,)` | int，1 = 该时间步是观测点（到位拍照），0 = 过渡 |
| `piece_pose_original` | `(7,)` | 原始世界系工件位姿 |
| `robot_pose_original` | `(7,)` | 原始世界系机器人位姿 |
| `seam_line` | `(N, 3)` | 原始焊缝中心线 |
| `seam_limits` | `(N, 2, 3)` | 原始坡口方向 |

`T_total = num_timesteps_init + (num_timesteps_next - 1) × num_transfer`
（`num_transfer` = 观测点数 - 1 段过渡；逐段拼接时每段去掉与上一段重合的首点）。

---

## 4. 控制/标记文件

| 文件 | 位置 | 含义 |
|------|------|------|
| `pose_done` | `output/<folder>/` | Pose 阶段完成标记（空文件） |
| `traj_done` | `output/<folder>/` | Traj 阶段完成标记 |
| `.done` | `output/<folder>/` | 子进程正常结束哨兵（controller 读后删除） |
| `.current_seam_pose` / `.current_seam_traj` | `output/<folder>/` | 当前处理中的 seam 名（超时心跳） |
| `blacklist_pose.txt` | `input/<folder>/` | 卡住/无解的 seam 名，每行一个 |
| `blacklist_traj.txt` | `output/<folder>/` | Traj 阶段卡住的 seam 名 |

---

## 5. 坐标与位姿约定

- 位姿统一为 7 维 `(x, y, z, qw, qx, qy, qz)`，四元数 **(w, x, y, z)** 顺序；
- Pose 阶段把世界系位姿变换到**工件坐标系**（piece 在原点）求解，便于复用单一场景；
- 机器人「底座」相对「输入 robot_pose」额外叠加 `base_transform = [0,0,0.26, 0.7071,0,0,0.7071]`
  （抬高 0.26m + 绕 z 轴 90°），这是机械臂安装座到 UR12e 基座的固定变换；
- 相机相对法兰（Link6）的变换在 `ik_cam_*.py` 中以常量 `camera_to_j6link_pos/rot` 给定。

调试查看 pkl 结构可用 `open_data.py`。
