# 06 — 配置参数速查

本文档列出 `config_pose.py` / `config_traj.py` 中的全部超参数及其含义，便于调参。

---

## 1. `ConfigurationPose`（Pose 阶段）

### 进化策略（ES）规模

| 参数 | 默认 | 含义 |
|------|------|------|
| `num_batches` | 8 | 独立搜索实例数（每个 batch 一套独立的观测进度状态机） |
| `num_iterations` | 100 | 单个焊缝段内未找到可行解的迭代上限（触发重置/换观测点） |
| `max_iterations` | 300 | `solve()` 主循环迭代上限 |
| `max_iterations_refine` | 40 | 精修阶段迭代次数 |
| `num_randoms_new` | 100 | 每次迭代每 batch 新采样的噪声 rollout 数 |
| `num_randoms_old` | 0 | 复用旧 rollout 数（0=不复用） |
| `num_randoms_all` | 101 | `new + old + 1`（含 1 条精英） |
| `num_select` | 2 | 计算概率时取代价最小的前 k 条 |
| `num_steps` | 5 | 焊缝段推进步长（`pts_list` 刻度） |
| `num_next` | 30 | 连续多少次更新无改善则判该段失败 |
| `num_poses` | 4 | 有这么多 batch 走完整条焊缝即停止 |
| `span` | 1 | 精修阶段每隔几轮存一张位姿快照 |
| `exponentiated_cost_sensitivity` | 5 | 概率指数权重的灵敏度 h（越大越「贪心」选最优） |

### 代价权重

| 参数 | 默认 | 含义 |
|------|------|------|
| `collision_cost_weight` | 25 | 碰撞 |
| `vision_pos_cost_weight` | 1 | 视觉位置代价合并系数 |
| `vision_rot_cost_weight` | 1 | 视觉旋转代价合并系数 |
| `dist_limit` | 0.5 | 距离归一化基准（下面三项除以它） |
| `insides_cost_weight` | 19/0.5 = 38 | 焊缝点在 FOV 内 |
| `space_cost_weight` | 21/0.5 = 42 | 视野空间遮挡（`has_space_cost=False` 时未启用） |
| `block_cost_weight` | 22/0.5 = 44 | raycast 遮挡 |
| `orientation_limit` | 30 | 方向代价归一化基准（度） |
| `orientation_cost_weight` | 23/30 | 观测方向 |
| `block_radius` | 0.04 | 遮挡 raycast 周围采样圆半径（m） |
| `num_block_pts` | 6 | 遮挡 raycast 圆周采样点数 |

### 开关与采样

| 参数 | 默认 | 含义 |
|------|------|------|
| `forced` | False | 是否强制单独拍焊缝首段/末段 |
| `has_space_cost` | False | 是否启用可微的视野空间代价（`computeVisionCost_0` 路径） |
| `refine` | True | 是否对选中位姿做精修 |
| `has_cov` | False | 是否从文件加载噪声协方差（否则用 `diag(sigma²)`） |
| `sigma` | `[0.1]*6` | 6 维（位置 xyz + 旋转 so3）高斯噪声标准差 |
| `scl` | 7/11 | 相机视锥 xy 缩放 |
| `scl_z` | 9.5/11 | 相机视锥 z 缩放 |

### 仿真规模

- `num_envs = num_batches × (num_randoms_new + num_randoms_old) = 8 × 100 = 800`

## 2. `ConfigurationTraj`（Traj 阶段）

### STOMP 规模

| 参数 | 默认 | 含义 |
|------|------|------|
| `num_batch` | 24 | 每条焊缝生成的 GT 轨迹数 |
| `num_dimensions` | 6 | 关节自由度 |
| `num_timesteps_init` | 51 | 起点→第一个观测点的轨迹时间步数（含两端） |
| `num_timesteps_next` | 51 | 相邻观测点间轨迹时间步数（含两端） |
| `num_iterations` | 20 | STOMP 迭代轮数 |
| `num_iterations_after_valid` | 0 | 找到可行解后额外迭代轮数 |
| `num_rollouts_new` | 30 | 每轮新采样的噪声轨迹数 |
| `num_rollouts_old` | 20 | 每轮复用的历史轨迹数 |
| `delta_t` | 0.1 | 时间步间隔（s） |
| `exponentiated_cost_sensitivity` | 2 | 概率指数权重灵敏度 h |

### 代价权重

| 参数 | 默认 | 含义 |
|------|------|------|
| `control_cost_weight` | 0.1 | 控制代价（对**加速度**） |
| `collision_cost_weight` | 20 | 碰撞 |
| `vision_cost_weight` | 1 | 视野代价合并系数 |
| `visible_cost_weight` | 1 | 点云可见性（`has_pc=True` 时） |
| `dir_cost_weight` | 0.25 | 相机朝向焊缝中点的方向代价 |

### 噪声/滤波

| 参数 | 默认 | 含义 |
|------|------|------|
| `initialization_method` | `LINEAR_INTERPOLATION` | 轨迹初始化方式（另有三次/最小控制代价可选） |
| `pre_filter` | False | 采样后是否先滤波 |
| `post_filter` | True | 更新后是否平滑滤波 |
| `noise_scale_high` / `noise_scale_low` | 1 / 1 | 噪声幅度（碰撞重/接近可行时切换） |
| `filter_scale_high` / `filter_scale_low` | 5 / 2 | 平滑强度切换 |

### 仿真规模

- `num_envs = num_batch × num_rollouts_new × 2 = 24 × 30 × 2 = 1440`

---

## 3. 调参建议

- **找不到 Pose 解**：调大 `num_randoms_new`、放宽 `orientation_limit`、检查 `scl/scl_z`（FOV 是否过小）、
  或确认黑名单是否误杀；`num_poses` 降低可更快停（但解更少）。
- **Pose 太慢**：减小 `max_iterations` / `num_randoms_new`，或减小 `POSE_TIMEOUT_MIN`（牺牲难 seam）。
- **Traj 碰撞过不去**：调大 `collision_cost_weight`、`num_rollouts_new`、`noise_scale_*`；或增大 `num_timesteps_*`（轨迹更细）。
- **Traj 不够平滑**：增大 `control_cost_weight` 或 `filter_scale_*`。
- **GPU 显存不足**：减小 `num_batches`/`num_batch`、`num_randoms_new`/`num_rollouts_new`（直接影响 `num_envs`），
  或减小 `PER_GPU_JOBS`。
- 随机种子 `seed=3` 固定在 `optimizer_pose.py` 与 `stomp_traj.py`，改它会改变全部随机结果。
