# Isaac Sim 焊缝观测避障场景构建

本文档记录如何在 Isaac Sim 中布置障碍物，使机械臂必须在避障的情况下达到指定位置。 

## 问题目标

基础场景包括：

- 机械臂
- 工件
- 工件上的焊缝目标点(如scripts/plan_seam.py中带偏移的goal_pose)
- 安装在机械臂末端或指定位置的相机

目标不是简单地在场景中增加障碍物，而是让障碍物满足以下效果：

- 机械臂默认观测路径被阻挡
- 默认相机视线被遮挡，或默认机械臂运动轨迹发生碰撞
- 机械臂仍然可以通过绕行、改变关节构型或改变观察角度看到焊缝指定位置
- 场景不能变成完全无解

## 障碍物放置的核心原则

障碍物应放在这种关键区域中：

1. 机械臂从初始姿态到默认观测姿态的运动通道附近

也就是说，障碍物应放在机械臂“最想走的路”上，而不是随意放在场景中。

## 推荐放置策略

### 1. 放在机械臂关节扫掠空间中

机械臂避障不应只考虑末端。很多情况下真正容易碰撞的是：

- Link2
- Link3
- Link4
- Link5
- Link6
- xiaoyu_accessory_link

可以先在无障碍条件下规划一条默认轨迹，然后记录关键 link 的运动轨迹，将障碍物放在这些Link经过的区域。
关键link包括：

俯视示意：

```text
机械臂基座 R
    \
     \   肘部默认轨迹
      \  o o o o o
          ███
          ███ 障碍物
              \
               相机观测位姿
```

这种方法可以迫使机械臂改变整体构型，例如抬肘、绕侧面或改变腕部姿态。

适用目标：

- 验证全身避障能力
- 避免只测试末端避障
- 构造更接近真实工装环境的机械臂运动约束

## 不建议的障碍物位置

### 1. 不要紧贴焊缝

如果障碍物紧贴焊缝目标点，可能导致务无解。

### 2. 不要出现在初始的默认free空间中，free空间指default.yaml中的init_free

靠近机械臂基座的障碍物会大范围限制机械臂可达空间，容易把问题变成单纯的运动学不可达，而不是“避障后可观测”。

### 3. 不要放在远离默认路径的位置

如果障碍物不在默认运动通道或默认视线通道附近，机械臂可能完全不需要绕行，无法体现避障效果。

## 判断障碍物是否放置合适

一个合适的障碍物布置应满足以下条件：

```text
1. 默认机械臂路径发生碰撞
2. 至少仍存在一个观测姿态可行
3. 机械臂为了到达新的观测姿态，需要明显绕开障碍物
```

如果不满足第 1 点，障碍物太弱，机械臂不需要避障。

如果不满足第 2 点，障碍物太强，场景可能无解。

如果不满足第 3点，障碍物虽然遮挡了局部视线，但没有真正构造出机械臂避障需求。

## 建议的场景构建流程

```text
1. 在无障碍场景中规划机械臂到焊缝观测位姿
2. 添加障碍物，需要和机械臂横扫过的空间有交集
3. 如果任务无解，减小障碍物尺寸或挪远一点
```

## 总结

障碍物的最佳位置不是焊缝点本身，也不是场景中的随机位置，而是：

```text
关键 link 扫掠空间
```
